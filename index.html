ちいさなGPT工房

文章を読ませて、自分だけの言語モデルをブラウザの中で一から育てます。サーバーには何も送りません。計算はこの端末の GPU (なければ CPU) で行います。

  1. 1文字を番号に出てくる文字に番号をふり、文章を数字の列にします。
  2. 2前の文字を読むTransformer が、直前の文字たちの関係を注意 (attention) で見ます。
  3. 3次の文字を予想次に来る文字の確率を、語彙のすべてについて出します。
  4. 4外れた分だけ直す本当の次の文字との差 (損失) が小さくなるよう、重みを少しずつ動かします。

学習データ

テキストファイルを開く

文章は多いほど上手になります。数千字なら言い回しのまね、数十万字あると文らしくなってきます。

質問に答えさせたいときは、「質問: …」「答え: …」の 2 行を空行で区切って並べます (「例: 質問と答え」を参照)。教えた質問や、言い方を少し変えた質問に答えるようになります。

JSON を読み込む

「JSON を読み込む」で、Colab で学習したモデル (tiny_gpt.json) もそのまま使えます。

GPU が無いときは Google Colab で大きく学習する
  1. Google Colab を開き、「ノートブックをアップロード」でリポジトリの colab/tiny_gpt.ipynb を選びます。
  2. メニューの「ランタイム → ランタイムのタイプを変更」で T4 GPU を選びます (無料枠で使えます)。
  3. 上から順にセルを実行します。自分の文章をアップロードするセルもあります。
  4. 最後のセルで tiny_gpt.json がダウンロードされます。この画面の「JSON を読み込む」で開くと、ここで文章を生成できます。
ChatGPT のように何でも答えさせたいとき

ここで一から作るモデルが答えられるのは、教えた質問とその言い換えまでです。教えていない質問にも答えさせるには、大量の文章で事前学習したモデルが必要です。colab/chat_finetune.ipynb は、日本語を話せる公開モデル (Qwen2.5) に、同じ「質問: … / 答え: …」の形のデータを LoRA で追加学習させ、自分の知識と口調を足します。Colab の T4 GPU で数分から十数分で終わり、チャット画面の URL も出ます。

モデルを学習させるか読み込むと、書き出しの続きを書きます。

「質問: (入力)」「答え: 」のあとを書かせ、改行が出たところで止めます。学習データに無い文字は読めないので外します。

温度を下げると無難に、上げると冒険的になります。「上位 k 個から」は確率の高い k 文字だけから選びます (0 は制限なし)。
